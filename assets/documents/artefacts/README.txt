Put your BA artefact PDFs in this folder, for example:
  stakeholder-register.pdf
  power-interest-matrix.pdf
  as-is-process-map.pdf
  to-be-process-map.pdf
  business-case.pdf
  sdlc-overview.pdf
Then open assets/js/data.js, find "artefacts", and set each "file" to the path,
e.g.  file: "assets/documents/artefacts/stakeholder-register.pdf"
